# Вывод средств — простая инструкция

У вас **два разных магазина** = **два разных Telegram-бота** и **два разных сервера**.

| | Главный магазин | Дочерний магазин (этот проект) |
|---|----------------|-------------------------------|
| Бот | Ваш основной бот | Бот дочернего магазина (WebApp) |
| Код | Другая папка / другой репозиторий | Эта папка `ucmagaz2` |
| Что делает с деньгами | Конвертирует ₽ в USDT, платит партнёру | Только кнопка «Вывести средства» |

---

## Что видит админ дочернего магазина

1. Открывает **своего** бота → `/admin` → **Вывести средства**
2. Пишет сумму в USDT
3. Жмёт **Binance** или **Bybit**
4. Пишет ID (UID) на этой бирже
5. Готово — заявка создана

Рубли в дочернем магазине **не трогаются**. Списывается только **USDT с баланса** (если он есть).

---

## Куда уходит заявка

Заявка приходит **не в дочерний бот**, а в **главный бот** — тому, кто владеет основным магазином.

Там сообщение примерно такое:

> Заявка на вывод #5  
> Магазин: Rakuta Shop  
> 100 USDT → Binance  
> ID: 123456789  
> [Кнопка: Выполнено]

Вы (владелец главного) переводите USDT человеку на биржу и жмёте **Выполнено**.

После этого дочернему админу в **его** бот приходит: «Вывод выполнен».

## Что нужно настроить

### Шаг 1 — база дочернего магазина

В Supabase **дочернего** проекта выполнить файл `supabase_treasury.sql`.

### Шаг 2 — файл `.env` на сервере дочернего магазина

```env
BOT_TOKEN=токен_бота_дочернего_магазина

MAIN_BOT_TOKEN=токен_бота_ГЛАВНОГО_магазина
MAIN_ADMIN_CHAT_ID=ваш_telegram_id

STORE_LABEL=Название дочернего магазина

TREASURY_API_SECRET=любая_длинная_парольная_строка_123
```

- **MAIN_BOT_TOKEN** — чтобы заявка пришла в главный бот  
- **MAIN_ADMIN_CHAT_ID** — ваш Telegram ID (узнать: @userinfobot)

### Шаг 3 — баланс USDT у дочернего

Пока на балансе 0 — вывести нельзя. Пополнить можно в Supabase:

```sql
UPDATE shop_balance SET balance_usdt = balance_usdt + 100 WHERE id = 1;
```

(100 = сколько USDT разрешить выводить)

Позже главный магазин сможет пополнять автоматически — для этого нужен код в **главном** проекте (см. ниже).

### Шаг 4 — код в главном магазине (обязательно)

Только дочернего проекта **мало**.

Когда вы жмёте **Выполнено** в **главном** боте, нажатие обрабатывает **сервер главного** магазина. Там нужно добавить логику из файла `MAIN_STORE_INTEGRATION.md` — иначе кнопка ничего не сделает (заявка зависнет в Telegram).

Кратко для разработчика главного проекта:

- В `.env` главного: `CHILD_STORE_API_URL` = адрес API дочернего сервера  
- Тот же `TREASURY_API_SECRET`, что у дочернего  
- При нажатии «Выполнено» — запрос на дочерний сервер «заявка #5 выполнена»

## Схема одной строкой

**Дочерний бот** (заявка) → **Главный бот** (вы перевели + Выполнено) → **Дочерний бот** (сообщение «готово»)

---

## Что НЕ в этом проекте

В `ucmagaz2` **нет**:

- конвертации рублей в USDT  
- учёта выручки по дням  

Это должно быть только в проекте **главного** магазина.
