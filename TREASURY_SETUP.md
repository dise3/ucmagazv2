# Вывод средств — простая инструкция

У вас **два разных магазина** = **два разных Telegram-бота** и **два разных сервера**.

| | Главный магазин | Дочерний магазин (этот проект) |
|---|----------------|-------------------------------|
| Бот | Ваш основной бот | Бот дочернего магазина (WebApp) |
| Код | Другая папка / другой репозиторий | Эта папка `ucmagaz2` |
| Деньги | Своя логика (конвертация и т.д.) | Вывод **в рублях** на Binance/Bybit |

---

## Что видит админ дочернего магазина

1. Свой бот → `/admin` → **Вывести средства**
2. Сумма **в рублях** (например `5000`)
3. **Binance** или **Bybit**
4. ID на бирже
5. Заявка уходит в **главный бот**

Списывается сумма с **рублёвого баланса** дочернего магазина.

---

## Куда уходит заявка

В **главный** бот:

> Заявка #5  
> 5 000₽ → Binance  
> ID: …  
> [Выполнено]

Вы переводите деньги партнёру (в рублях / на биржу — как договорились) и жмёте **Выполнено**.

Партнёру в дочернем боте: «Вывод выполнен».

## Настройка

### 1. Supabase

Выполнить `supabase_treasury.sql` (если уже была старая версия с USDT — скрипт переименует колонки).

### 2. `.env` дочернего сервера

```env
BOT_TOKEN=...
MAIN_BOT_TOKEN=токен_главного_бота
MAIN_ADMIN_CHAT_ID=ваш_telegram_id
STORE_LABEL=Название магазина
TREASURY_API_SECRET=общий_секрет_с_главным
```

### 3. Баланс в рублях

```sql
UPDATE shop_balance SET balance_rub = balance_rub + 5000 WHERE id = 1;
```

Или с главного сервера: `POST /api/treasury/credit` с `{ "amount": 5000 }`.

### 4. Главный проект

См. `MAIN_STORE_INTEGRATION.md` — обработка кнопки «Выполнено».

1. Перезапустить сервер (`npm start` в `server`).
2. В боте снова отправить **`/admin`**.
